# Введение в MAP Framework

## Что такое MAP?

**MAP** (Modular Agentic Planner) — когнитивная архитектура для AI-агентов, вдохновлённая функциями префронтальной коры головного мозга.

**Научная база:**
- Основана на исследовании **Nature Communications (2025)**: улучшение производительности на **74%** в задачах планирования
- Расширена системой **ACE** (Agentic Context Engineering) из arXiv:2510.04618v1
- Оптимизирована для **Claude Code CLI**

**Текущая версия:** 2.2.0 (Phase 1 Context Engineering Complete)

## Основные концепции

### 8 Специализированных Агентов

MAP координирует работу 8 агентов через Orchestrator:

1. **TaskDecomposer** — разбивает цели на атомарные подзадачи
2. **Actor** — генерирует код и решения
3. **Monitor** — валидирует качество, безопасность, корректность
4. **Predictor** — анализирует влияние изменений на кодовую базу
5. **Evaluator** — оценивает качество решения (функциональность, безопасность, тестируемость)
6. **Reflector** — извлекает уроки из успехов и неудач
7. **Curator** — управляет базой знаний (playbook)
8. **DocumentationReviewer** — проверяет полноту и корректность документации

**Orchestrator** — логика координации workflow, реализованная в slash-командах (`.claude/commands/map-*.md`), не отдельный шаблон агента.

### Интеграция с MCP Серверами

MAP использует **6 MCP серверов** для расширения возможностей:

- **cipher** — база знаний для хранения успешных паттернов
- **claude-reviewer** — профессиональный code review с анализом безопасности
- **sequential-thinking** — цепочки рассуждений для сложных задач
- **codex-bridge** — генерация кода (требует 10-minute timeout)
- **context7** — актуальная документация библиотек
- **deepwiki** — анализ GitHub репозиториев

### ACE Playbook — Система Обучения

**Структура:**
- Хранится в `.claude/playbook.json`
- **9 категорий паттернов**: архитектура, реализация, безопасность, производительность, ошибки, тестирование, качество кода, использование инструментов, отладка
- **top_k = 5**: возвращает только 5 наиболее релевантных паттернов для уменьшения когнитивной нагрузки
- **Автоматическое обучение**: Reflector извлекает паттерны из каждой задачи, Curator обновляет playbook инкрементально

## Преимущества

### Оптимизация Стоимости

**Стратегия распределения моделей:**
- Predictor, Evaluator: **haiku** (быстрый анализ)
- Actor, Monitor, TaskDecomposer, Reflector, Curator: **sonnet** (критичное качество)
- Orchestrator: **opus** (критические решения workflow)

**Экономия:** 40-60% снижение затрат vs использование sonnet везде

### Context Engineering (Phase 1)

**Recitation Pattern:**
- Создаёт `.map/current_plan.md` с визуальными маркерами прогресса (✓, →, ☐, ✗)
- Держит цели "свежими" в контексте на длинных задачах
- **Эффект**: +20-30% успешность на сложных задачах, +50% наблюдаемость прогресса

**Оптимизация шаблонов:**
- Monitor: -97 строк (-9.6% оптимизации)
- Evaluator: -90 строк (-9.6% оптимизации)
- Суммарная экономия: 187 строк кода шаблонов

### Установка

**4 способа установки:**

1. **Plugin Marketplace** — через Claude Code plugin system
2. **mapify CLI** (рекомендуется):
   ```bash
   uv tool install mapify-cli --from git+https://github.com/azalio/map-framework.git
   mapify init my-project
   ```
3. **Clone Repository** — клонирование репозитория
4. **Copy Agents** — копирование агентов в существующий проект

**Требования:** Python 3.11+
