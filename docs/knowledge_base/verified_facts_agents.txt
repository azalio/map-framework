**Source:** .claude/commands/map-feature.md

**Orchestrator Workflow (Automated Sequential):**
```
1. TaskDecomposer → Break feature into subtasks
2. FOR EACH subtask:
   3. Actor → Implement
   4. Monitor → Validate
      IF invalid: feedback to Actor (max 3-5 iterations), goto step 3
   5. Predictor → Analyze impact
   6. Evaluator → Score quality
      IF not approved: feedback to Actor, goto step 3
   7. ACCEPT changes (apply to files)
   8. Reflector → Extract lessons (MANDATORY)
   9. Curator → Update playbook (MANDATORY)
   10. Apply Curator delta operations
   11. Sync to cipher if helpful_count >= 5
3. NEXT subtask
4. Final summary and cleanup
```
